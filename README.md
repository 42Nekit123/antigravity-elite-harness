## 🚀 Overview

**Antigravity Elite Harness** is a production-grade suite of global rules and specialized skills designed to transform your **Google Antigravity** agent into an elite pair-programmer and frontend designer.

By combining **Anthropic's 7-vector review methodology**, **strict anti-bandaid engineering invariants**, and a **meticulously calibrated design system**, this harness eliminates:
- ❌ Fragile `if (id === 'special-case')` bandaids and silent test failures.
- ❌ Generic, ugly AI-generated UI (acid purple gradients, blur, drop-shadow soup, bold-everything).
- ❌ Unplanned code mutations and hallucinated API signatures.

## 🛠️ How to Use

### 1. Automatic Behavioral Protection (Always Active)
Once installed, `AGENTS.md` is automatically injected into every conversation turn in Antigravity. Your agent will automatically:
- Check neighboring files before writing code to match their exact style and comment density.
- Refuse to write hacky bandaids, choosing to fix underlying mechanisms instead.
- Report test failures with exact stdout/stderr instead of quiet retries or loosening assertions.

### 2. Deep Multi-Angle Code Review
Before committing or merging code, simply ask:
```text
"Review my diff for bugs" or "Use code-review skill on my branch"
```
The agent executes the 7-vector audit:
1. **Line-by-line scan**: Checks inverted conditions, off-by-one, null derefs, missing awaits, swallowed catch errors.
2. **Removed-behavior auditor**: Checks where invariants from deleted lines are re-established.
3. **Cross-file tracer**: Checks all callers and callees for broken contracts.
4. **Altitude check**: Flags bandaids layered on shared infrastructure.
5. **Verification phase**: Ranks findings as `CONFIRMED` or `PLAUSIBLE`, dropping false positives.

### 3. Scandinavian Minimalist UI Generation
When building any frontend, dashboard, or component, simply say:
```text
"Build a dashboard for telemetry with dark/light themes"
```
The agent activates `ui-design-system`, enforcing:
- Token-first build order (`:root` tokens -> Base -> Primitives -> Components -> Pages).
- Restrained typography (400 regular, 500 bold only).
- Banning cheap AI gradients, heavy drop shadows, and visual emoji filler.
