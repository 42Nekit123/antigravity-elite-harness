# MAYHEM Analytics — High-Frequency Stream Intelligence Dashboard

A modern, standalone, single-page landing page and live interactive telemetry dashboard for real-time stream intelligence, built with pure HTML5, CSS3, and lightweight vanilla JavaScript.

---

## 🌟 Visual Theme & Design Foundations
- **Cyber HUD Vector Aesthetics**: Concentric orbiting telemetry radar rings, rotating reticle arcs, frequency spectrum bars, and live coordinate readouts inspired by high-tech techno HUDs.
- **Dual-Theme Support (Dark & Light)**:
  - **Dark Mode**: Deep obsidian (`#09080e`), graphite surfaces (`#171520`), and glowing Ruby/Crimson accents (`#ff2a5f`).
  - **Light Mode**: Crisp slate (`#fbfbfe`), pure white surfaces (`#ffffff`), and deep ruby accents (`#d9043d`).
  - **Strict Contrast**: Exceeds WCAG AA ratio (> 4.5:1) in both modes.
- **Design System Rules**:
  - Restrained typography: font-weight strictly `400` and `500`.
  - Sentence case across all UI headings, buttons, and labels.
  - Zero external bloat: 100% pure SVG icons, vectors, and vanilla code.

---

## 📁 File Structure
- `index.html` — Semantic single-page HTML5 structure.
- `styles.css` — CSS design tokens, responsive layout, cyber HUD styling.
- `app.js` — Live stream simulator, dynamic SVG spline chart, 5-axis threat radar, event terminal & cost calculator.

---

## 🚀 How to Run
Open `index.html` directly in any web browser, or run:
```powershell
Start-Process "./index.html"
```
